Timing

The finished colour ends

This model has no door sensor, so the finished colour ends after the set time instead. Your choice is kept for a model that has one.

The printer's own light

The controller can switch the printer's chamber light too. Each of these is separate.

Your printer

What the door does

Opening or closing the door wakes the strip and restarts the idle timer. If the finished colour ends "when the door opens", it ends. That's all: the door never changes your settings.
